# RoboJackets Furi Bot

An autonomous 500 g sumo robot developed as part of the RoboJackets RoboWrestling Software Team at Georgia Tech.

## Overview

Furi Bot is an autonomous robot designed to detect opponents, navigate the competition ring, and push opposing robots out of the arena. We worked on the robot's software development, focusing on sensor-based detection and movement control.

## Features

- **Opponent Detection:** Uses sensors to detect and respond to opposing robots.
- **Line Detection:** Identifies the boundaries of the competition ring to prevent the robot from driving out of bounds.
- **Autonomous Movement:** Uses sensor input to make real-time decisions during matches.

## Technologies

- **Languages:** C++
- **Hardware:** Arduino, Teensy 4.1, Arduino Nano
- **Tools:** Git, GitHub

## Results

- Placed **3rd in an in-house RoboWrestling competition**.

## Future Improvements
